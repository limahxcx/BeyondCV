# Changelog

## 0.1.0 — MVP foundation

- Added the React, TypeScript, and Vite application shell with an English, Brazilian Portuguese, and Spanish interface.
- Added local PDF, DOCX, and TXT text extraction and deterministic resume scoring.
- Added a browser-local resume editor, impact interview, job-text comparison, and PDF/DOCX/JSON export.
- Added IndexedDB storage, PWA shell, and Cloudflare static asset configuration.
- Documented scoring, privacy, local development, and known limitations.
