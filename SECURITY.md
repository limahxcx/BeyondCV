# Security policy

BeyondCV handles resume content locally in the browser. The project does not have a production backend or a managed vulnerability disclosure service configured yet.

If you find a security issue, do not publish personal resume data, credentials, or a working exploit in a public issue. Contact the repository maintainers privately once a public repository and security contact have been configured. Until then, avoid sharing sensitive information with this local project.

Please include affected versions, impact, and a minimal reproduction using synthetic content. The project makes no claim of security certification or legal compliance.
